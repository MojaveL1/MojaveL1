01the work

The node does not trust the miner.

You ask the node for a block template with your address at the bottom. That template holds the header, the current difficulty and the Argon2id parameters, so you can hash the same bytes the node will hash.

argon2id(header | nonce) × difficulty < 2^256

Send back the nonce. The node recomputes the hash itself, and only then does it accept the block. A miner that lies wastes its own time, and nothing else.

Difficulty retargets every block toward a thirty second block time, inside a band, so a sudden arrival of miners cannot stall the chain for an hour.

Pick whichever is closer to where you already are.

The miner at /mine runs Argon2id in WebAssembly, one worker per thread. Rewards go to the address you paste in, classic or quantum. The tab has to stay open, and a phone will be slower than a desktop.

open /mine

Run the CLI against any node

Same work, no browser in the way. Point it at the public node, or at your own copy of the repository, and give it as many threads as you have cores.

one file miner/miner.js
# clone, install, mine
git clone https://github.com/MojaveL1/MojaveL1
cd MojaveL1
npm install
node miner/miner.js YOUR_MJC1_OR_MJCQ1_ADDRESS --threads 8

# or against a node you run yourself
node miner/miner.js YOUR_ADDRESS --node http://localhost:8266
03what you earn

A reward, then two minutes of waiting.

Each block pays its miner, plus the fees of the private transactions inside it. Testnet rewards are the emission schedule on the token page: falling smoothly, then two tMOJAVE per block forever.

Coinbase outputs mature after three blocks, roughly ninety seconds. Until then they show as locked and cannot be spent, and cannot be used as a decoy either, so a miner's own fresh coins never end up in someone else's ring.

There is a leaderboard at /mine. It counts public blocks per payout address and shows a short fingerprint rather than the address itself, because publishing a payout address would publish the person.

the honest part

The testnet is one node today. Difficulty is low enough that a single machine can find blocks, which is a fair description of a testnet and a poor description of a network. Mining it is for testing the mechanics, not for income.

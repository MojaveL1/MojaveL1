What is Mojavechain, in one sentence?

A proof of work chain where every transaction hides its sender, its receiver and its amount, and where payments to quantum addresses are found with a lattice cipher instead of elliptic curves.

Is there a transparent mode?

No. There is no public ledger view to opt into and no shield button to forget. An address either receives a private output or receives nothing. Amounts travel as commitments, so even the block explorer shows a point rather than a number.

Is it quantum safe today?

Receiving is. A mjcq1 address carries an ML-KEM-768 key, the sender encapsulates a fresh secret for every payment, and the 1,088 byte ciphertext is stored with the output. A quantum computer recording the chain today cannot derive the shared secret later.

Spending is not, yet. Ring signatures and key images still rest on the discrete log problem. Faraday replaces them with hash based proofs and widens the anonymity set from 16 outputs to the whole chain. Until it ships, treat the spend side as a delay rather than a guarantee.

Why are the quantum addresses so long?

Because an ML-KEM-768 public key is 1,184 bytes. Base58 encoded alongside the spend and view keys, an mjcq1 address lands around 1,715 characters. Wallets copy and paste the whole thing, and the wallet screen offers a QR code for phone to phone transfer. A classic mjc1 address is 97 characters and works the same way, minus the lattice key.

How do I get coins to try it?

The faucet in the wallet sends 25 tMOJAVE, once an hour per address, into a private output. You can also mine: open /mine and leave the tab running, or run node miner/miner.js YOUR_ADDRESS. Mining pays whatever difficulty you can beat, so a laptop still finds blocks on a testnet this size.

Why does a fresh coin show as locked?

Every output needs three confirmations before it can be spent, and the same rule applies to ring members, so an output younger than three blocks cannot be used as a decoy either. At a thirty second block time that is about ninety seconds of waiting. The rule exists so a miner cannot spend the reward from the block they just found inside a ring that someone else is building.

What is the difference between $MOJAVE and tMOJAVE?

$MOJAVE is the project token on Solana. It funds development and carries the community to mainnet. tMOJAVE is the coin this testnet mints, it comes from the faucet or from mining, and it has no value and cannot be sold. Testnet balances will be wiped before mainnet, by design.

Is there a premine?

Not on the chain. Genesis starts with nothing emitted, every block pays the miner who found it plus the fees inside it, and the first block carries no special allocation. The reward curve is (100,000,000 − emitted) / 2^19, then a flat 2.0 per block forever, so mining never stops being paid.

Do I have to trust the node to check a transaction?

No. Every transaction page has a verify button. Your browser pulls the transaction and its ring members from /api/rawtx/:id and runs the same verifyTx the node runs: each ring signature, each range proof and the balance of the commitments. If the node lied, your browser would say so.

What are the cryptography libraries?

ristretto255 and SHA3 come from @noble/curves and @noble/hashes, ML-KEM-768 comes from @noble/post-quantum, and Argon2id is built into Node. Nothing is hand rolled. The test suite covers stealth scanning, lattice detection, range proofs, ring signatures, forged signatures and double spends, and it runs on every push.

Has the code been audited?

A full protocol audit has not been published. The primitives are audited libraries and the chain logic is small enough to read, but reading it is currently the only assurance on offer. That is why every claim on this site is written so you can test it instead of believing it, and why this site says testnet rather than mainnet.

When mainnet?

After Faraday. The order is deliberate: shipping a mainnet on elliptic curve ring signatures would mean launching a chain that needs a hard fork to become what it claims to be. Faraday first, then genesis with it switched on from block 1. No second coin, no migration sale.

Can I run the whole thing myself?

Yes, and it is one process. Clone the repository, run npm install and npm start, and you have a node, an explorer, a wallet and a faucet on localhost:8266. Node 24 or newer. Set PORT, DATA_PATH, BLOCK_SEC or ARGON_KIB if you want different behaviour.
